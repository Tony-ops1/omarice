# Projektant elektro omaric — P/U RM 3

Spletna aplikacija za idejno razporeditev opreme v priključno-merilni omarici po tehnični smernici Elektro Ljubljana TS 30.

## Kaj omogoča
- Povečan, pregleden prikaz omarice.
- Dodajanje, premikanje, spreminjanje in brisanje komponent.
- Primer z glavnim ločilnikom 250 A ter dvema 160 A.
- Pogled na merilni del in celotno omarico.
- Popis materiala, shranjevanje projektov in izvoz.

## Zagon
Odprite `index.html` v brskalniku ali omogočite GitHub Pages:
**Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.

Predvideni javni naslov je:
https://tony-ops1.github.io/omarice/

## Pomembno
To je **idejni konfigurator**, ne potrjen izvedbeni elektro projekt. Dejanske mere in ustreznost opreme, zaščite, povezav, tokov in montažnih pogojev je treba strokovno preveriti. Podatki in spremembe v lokalnem pomnilniku se med napravami ne prenašajo samodejno; projekt izvozite za varnostno kopijo.
